## About
This project contains exercises using JSON, JavaScript fetch(), and jQuery.

## Files
- `books.json` — book data in JSON format
- `books.html` — loads and displays the book data
- `jquery-dom.html` — demonstrates jQuery text, style, and click events

## How to Run
1. Open this folder in Visual Studio Code.
2. Start Live Server for `books.html`.
3. To view the jQuery exercise, open `jquery-dom.html` with Live Server.
4. Keep `books.json` and `books.html` in the same folder. An internet connection is needed to load jQuery from its CDN.
